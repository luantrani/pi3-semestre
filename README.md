# pi3-semestre

Projeto de monitoramento de prateleiras usando sensores de peso. Interface estática em HTML e CSS para visualizar o status das prateleiras em tempo real.

## Funcionalidades

- **Visão Geral** (`index.html`): Dashboard com KPIs, status das prateleiras e alertas recentes.
- **Configurações IoT** (`config-iot.html`): Cadastro e listagem de sensores.
- **Relatórios** (`relatorios.html`): Análises e insights sobre o monitoramento.
- **Painel do Repositor** (`repositor.html`): Foco em prateleiras que precisam reposição.
- **Login** (`login.html`): Tela inicial de acesso ao sistema.

## Tecnologias

- HTML5
- CSS3

## Como executar

Abra qualquer arquivo `.html` em um navegador web. Navegue entre as páginas usando o menu lateral.
